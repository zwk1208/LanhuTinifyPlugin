# Lanhu Resource Assistant IntelliJ Platform 插件

这是一个 Android Studio/IntelliJ Platform 插件，用于导入本地 PNG、JPEG 和 WebP
资源，并按需通过 [Tinify](https://tinypng.com/developers) 压缩。插件不会抓取
Lanhu 网页 DOM；蓝湖设计稿入口仅通过分享接口读取有权限的图片。工具窗口、按钮、提示、
状态信息和对话框均为中文；PNG/JPG/WebP、
API Key、drawable-* 等技术名称保留原写法。

## 构建

要求：JDK 17，以及用于下载 Gradle/IntelliJ Platform 依赖的网络连接。

完整的前期配置和使用步骤请查看：[插件使用说明](docs/USAGE.md)。

```powershell
.\gradlew.bat test
.\gradlew.bat buildPlugin
```

生成的 ZIP 位于 `build\distributions`，可通过
**Settings/Preferences → Plugins → 齿轮 → Install Plugin from Disk** 安装。
重启 IDE 后，从 **View → Tool Windows → Lanhu Resource Assistant** 打开工具窗口。

## 使用 API 密钥

在“1. 导入设置”区域底部的“Tinify API 密钥”中填写 API 密钥并点击“保存密钥”。
密钥通过 IntelliJ 的 `PasswordSafe` 保存，不会写入项目文件，也不会记录到日志。
插件直接使用 Tinify 的 HTTPS API。

## 使用方法

1. 如需从蓝湖设计稿导入，先在顶部“蓝湖设计稿”中粘贴分享链接或某个页面的详情地址。
   项目详情地址（通常包含 `pid`、`tid` 和 `image_id`）只会读取该页面，不会列出整个项目。
   点击“打开链接”，
   在浏览器中完成蓝湖登录、加入团队或输入分享密码；然后从浏览器开发者工具复制
   `lanhuapp.com` 的 Cookie，填入“蓝湖登录 Cookie”并保存。Cookie 通过 IntelliJ
   `PasswordSafe` 保存，不会写入项目或输出到日志。界面中的“登录提示”紧跟在登录态下方，
   “设计稿读取状态”单独显示在蓝湖链接下方。点击“读取设计稿…”后，插件会
   先依次读取并汇总所有蓝湖链接的页面和切图，再弹出一个统一选择框；在弹框中勾选要导入的图片，
   并逐项选择 `drawable-mdpi`、`drawable-hdpi`、`drawable-xhdpi`、
   `drawable-xxhdpi` 或    `drawable-xxxhdpi`，确认后才会下载并加入下方图片列表。
   对项目链接会自动读取页面详情 JSON 中的可下载切图；统一弹框中可逐张勾选切图，
   并逐项选择图片格式（PNG/WebP）、蓝湖导出分辨率（例如 `PNG xxxhd`、`PNG xhd`）
   和目标 Android density。
   多个设计稿会显示设计稿来源前缀；其中一个设计稿或页面读取失败时，会保留错误信息并继续汇总其他设计稿。
   选择弹框包含“导入”复选框和预览列，可以只勾选需要的单张图片；预览加载失败时仍可按名称和尺寸判断后导入。
   插件只将页面 JSON 中明确标记为资源/导出图层的节点列为切图；
   Figma 的 `ddsImage` 图片填充层不会进入列表，普通图片图层不会仅因存在
   `imageUrl` 就进入列表。页面没有可解析的切图时，
   插件会回退为导入页面整图。
   如果蓝湖只返回一条 OSS `imageUrl` 而没有多条 density URL，插件会根据图层逻辑尺寸
   生成 mdpi、hdpi、xhdpi、xxhdpi、xxxhdpi 的 OSS resize 地址；在“蓝湖分辨率”列选择
   不同项时，像素尺寸和最终下载文件会同步使用所选倍率。此类图片同时生成 PNG/WebP
   两种可选格式；如果某张图片只有一种实际格式，格式下拉只显示可用格式，避免出现空白选项。
   如果使用的是包含 `image_id` 的单页面详情地址，插件会跳过页面整图选择，直接读取该页面下的切图；
   只有读取不到切图时才回退为页面整图。
   如果页面详情接口仍无法解析切图，可在蓝湖右侧切图弹框中选择全部切图并点击“下载全部切图”，
   保存 ZIP 后切换到“文件导入 → 选择 ZIP…”导入。不要把 `blob:https://lanhuapp.com/...`
   地址粘贴到插件：顶部按钮通常不是返回一个可复制的 ZIP 地址，而是由蓝湖前端逐张下载图片后
   在当前浏览器内用 JSZip 生成 ZIP；`blob:` 地址只在生成它的浏览器标签页内有效，插件无法跨进程读取。
   蓝湖分享链接通常受团队权限、登录态和有效期限制；蓝湖私有网页接口可能随服务端
   变化，读取失败时请先在浏览器确认该链接可以正常打开。
   蓝湖链接输入框支持一次粘贴多条链接（每条一行）；从蓝湖复制的包含分享人、团队名称和有效期的整段文本也会自动提取链接，
   多个项目会按顺序读取并将图片追加到同一个列表。
2. 在工具窗口顶部“导入设置 → 文件导入”中点击“选择图片…”或“选择 ZIP…”，并按需设置回退密度。
   ZIP 中的
   `drawable-*`、`mipmap-*` 以及单独的 `mdpi`/`hdpi`/`xhdpi`/`xxhdpi`/
   `xxxhdpi` 目录会自动识别，ZIP 根目录的图片也支持。
   导入按钮旁会显示读取进度；导入期间会暂时拦截其他操作，并可点击“取消导入”。
3. 对于独立文件或无法识别目录的 ZIP 条目，回退密度默认为 `xxhdpi`。每行都会保存明确的目标目录；未识别密度时默认是
   `drawable-xxhdpi`。
4. 在“3. 图片列表”中检查列表。表格列顺序为“预览”“原文件名”“原始大小”“尺寸”“格式”“目标名称（可编辑）”“目标资源目录（可编辑）”“导入工程”“需要压缩”； 
   后两列是醒目的可单击切换复选框，默认均已勾选且相互独立。取消“导入工程”会完全排除该行；取消
   “导入工程”是前提；取消“导入工程”后“需要压缩”会失效且不可勾选。未勾选“需要压缩”
   会直接写入该行的原始字节，不需要 API 密钥。黄色的目标名称和目标
   目录单元格可编辑。
5. 选择一行或多行后，可在表格下方使用“应用到选中行”；也可以使用“应用到
   全部”批量设置目标目录或名称前缀。名称前缀操作与“导入工程”复选框无关，
   重复应用安全前缀不会重复添加。   `drawable-*` 和 `mipmap-*` 目录都会识别并可作为输出目录；表格列名称为“目标资源目录”，
   批量编辑也会直接应用这个实际目录。
6. 在“2. 目标目录”中填写或选择 Android 模块根目录、`src/main/res` 或 `res` 资源根目录。
   插件会扫描该根目录下已有的 `drawable-*` 和 `mipmap-*` 子目录，并把它们填入图片列表的“目标资源目录”选择项，
   包括 `drawable-ar-xxhdpi`、`mipmap-xxhdpi` 这类语言/版本限定符目录；如果对应 density 没有现成目录，
   才使用标准 `drawable-<density>` 或 `mipmap-<density>` 作为新建目录。目标目录字段不是最终资源子目录本身。
7. 在底部“4. 处理操作”中点击“处理已导入图片”。只有勾选“导入工程”的行会写入。勾选“需要压缩”的行
   使用 Tinify；Tinify 不可用或压缩失败时，可选择回退为原始字节。未勾选
   “需要压缩”的行从不需要 API 密钥。处理后会刷新 IDE 的 VFS，并通过通知提醒将
   生成的文件会刷新到 IDE，并在目标目录位于 Git 仓库时自动执行 Git add；若无法找到 Git
   仓库或执行失败，通知会说明原因并提示手动添加。导入和处理期间，对应按钮右侧会显示阶段文案和百分比，
   并暂时拦截其他编辑操作；可使用旁边的取消按钮中断当前操作。

名称必须只包含小写字母、数字和下划线。支持 PNG、JPG、JPEG 和 WebP；AVIF
以及无效条目会以中文提示跳过。目标文件已存在时会逐项询问，选择覆盖或跳过当前文件；
跳过不会中断其他图片的导入。压缩支持
取消、进度显示和临时服务器/限流错误重试，每批最多处理 20 张图片。

蓝湖或本地文件名如果包含中文，目标名称会优先使用内置的常见英文短语映射；
未匹配的汉字使用本地离线拼音转换，最终仍会生成符合 Android 资源规则的小写英文名称。
目标名称仍可在图片列表中逐项修改；不会调用外部翻译服务，也不会把 Unicode 字符写入资源名。

## 限制

- 不解析蓝湖网页 DOM，也不执行项目同步；蓝湖设计稿入口仅调用分享解析和项目图片接口。
- 页面内切图优先来自蓝湖详情接口返回的 `json_url` 页面 JSON；如果页面使用 DDS
  数据，则回退读取 `multi_info` 和 DDS Schema。上述接口属于蓝湖内部接口，
  不同设计稿来源（Sketch、Figma、PS 等）的图层字段可能不同。当前仅导入可解析为
  PNG/JPG/JPEG/WebP 的切图，SVG/PDF 等格式会跳过。
- 蓝湖详情页是单页应用，HTML 本身不包含完整切图列表；插件不会通过抓取 HTML/DOM
  绕过登录，而是使用用户提供的有效 Cookie 调用页面数据接口。
- 蓝湖顶部“切图下载”按钮是浏览器端打包流程：它接收右侧弹框的切图对象数组，逐项下载真实图片，
  再在浏览器内生成 ZIP。因此通常不存在可直接复用的服务端 ZIP 下载 API；要自动读取这批切图，
  需要浏览器扩展/桥接程序把当前页面的切图对象或已下载文件传给插件。
- 蓝湖读取失败提示会标明当前阶段（页面详情、页面 JSON、DDS 备用、资源签名、预览或下载）；
  401/403 资源会自动尝试 `project/sign_url`，若仍失败请重新复制登录态 Cookie，并确认团队允许导出切图。
- Tinify 的调用次数和计费规则仍然适用。
- ZIP 密度识别支持 Android `drawable-*`/`mipmap-*` 目录和单独的密度目录；
  其他布局使用选定的回退密度（默认 `xxhdpi`）。
- 输出目录支持 `drawable-*` 和 `mipmap-*` density 目录，也支持语言/版本限定符。
- 蓝湖导入选择了明确的 PNG/JPG density 时，插件会按导出 density 与目标 Android density
  缩放像素后再写入对应 `drawable-*` 目录；无法识别导出 density 的原图/自定义 URL 不缩放。
  对没有明确倍率字段的图片，会尝试根据蓝湖图层逻辑尺寸和下载文件像素尺寸推断倍率。
